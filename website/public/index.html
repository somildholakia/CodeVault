06 GOOD TO KNOW

A few things
you might be
wondering.

Clear answers, no fine-print maze.

Is CodeVault a desktop app? ＋

CodeVault is a browser-based web application. The public download currently contains its source code; there are no packaged Windows, macOS or Linux installers yet.

Can I run it on my own machine? ＋

Yes. Install Node.js 20.11 or newer, Git 2.30 or newer and MongoDB, configure the root environment file, then run npm install and npm run dev.

Does it use real Git? ＋

Yes. Repository operations use the Git CLI and real Git data. MongoDB stores application metadata such as accounts, collaborators, issues and review records.

Is it ready for production hosting? ＋

The project includes deployment configuration, but production use needs MongoDB, a persistent backend disk for Git repositories, secure environment variables, backups and additional operational hardening. See the README before hosting important source code.

Where do I report a bug or suggest something? ＋

Open an issue in the public GitHub repository. Include steps to reproduce, expected behaviour and any relevant logs, while keeping secrets out of the report.
